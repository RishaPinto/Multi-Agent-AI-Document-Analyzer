# 🤖 Multi-Agent AI Document Analyzer

An AI-powered multi-agent system that analyzes uploaded documents using specialized Large Language Model (LLM) agents.

## 🚀 Features

- 📄 Document Summarization
- 🧠 Key Insight Extraction
- ⚠️ Risk & Issue Detection
- 💡 Recommendation Generation
- 🧑‍💻 Technical/Software Engineering Analysis
- 🤖 Multi-Agent Coordination
- 🌐 Interactive Streamlit UI

---

## 🛠️ Technologies Used

- Python
- Streamlit
- LangChain
- Groq API
- Llama 3.1
- Multi-Agent Systems
- Prompt Engineering

## ⚙️ How It Works

1. User uploads a text document.
2. The Coordinator sends the document to multiple AI agents.
3. Each agent performs a specialized task:
   - Summary Generation
   - Insight Extraction
   - Risk Analysis
   - Recommendations
   - Technical Evaluation
4. Results are displayed on the Streamlit dashboard.

## ▶️ Run the Project


